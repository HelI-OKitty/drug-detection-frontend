# 탐지 목록·상세 UI 개선

스크린샷은 임시 개발 페이지에서 **디자인 확인용 예시 데이터**로 촬영했습니다. 실제 서버 데이터가 아니며 촬영 후 임시 페이지를 제거했습니다.

- list-desktop.png: 판정·검토 상태·기간 필터
- list-filtered.png: 텍스트·이미지 양성 OR 복수 선택
- detail-desktop.png: 종합·텍스트·이미지·OCR와 검토 상태 분리
- list-mobile.png / detail-mobile.png: 390px 화면

목록 API에 개별 판정이 없으면 해당 유형 필터가 비활성화됩니다. OCR은 별도 판정 계약이 확정되지 않아 연동 대기로 표시합니다. 미제공 값을 음성으로 간주하지 않습니다.

브라우저 검증: 복수 유형 선택, URL 조건 유지와 새로고침, 페이지 변경 및 필터 변경 시 1페이지 복귀, 빈 결과 초기화, 미제공 유형 비활성화, 모바일 가로 넘침 확인.
