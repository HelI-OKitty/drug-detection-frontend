# 관리자 상세 검토 화면

스크린샷은 임시 개발 페이지에서 예시 데이터와 중립적인 예시 이미지를 사용해 촬영했습니다. 실제 게시글·AI 분석 결과가 아닙니다. 촬영용 페이지와 데이터는 제거했으며 운영 경로에는 포함되지 않습니다.

- `desktop.png`: 원문·분석 근거와 우측 검토 처리 영역 (1440px 화면)
- `mobile.png`: 390px 화면, 이미지·OCR 및 검토 처리의 세로 배치
- `delete-confirmation.png`: 별도 삭제 영역의 확인창

## 변경 사항

- 원문 링크와 근거별 바로가기, 텍스트 판정 방식, 이미지별 판정 및 OCR 추출 내용 구분
- 검토 처리 카드를 우측 상단에 배치하고 삭제를 별도 영역으로 분리
- `review_status=confirmed`의 실제 동작에 맞춰 버튼을 ‘검토 확정’으로 표시 (AI 판정은 변경하지 않음)
- 삭제 확인창은 네이티브 dialog 사용: 취소 버튼 초기 초점, 배경 조작 차단, Esc 닫기
- 전체 게시·탐지 시각과 긴 게시글 ID를 표시

## 검증

- 브라우저: 양성·음성·미제공·확정 상태, 원문 링크와 근거 이동, 필터를 유지하는 목록 복귀 링크, 이미지 확대·Esc 닫기, 삭제 취소·초점·배경 조작 차단
- 모바일: 페이지 전체의 가로 넘침 없음
- API 테스트: 검토 확정 요청은 `review_status`만 변경
- 실제 운영 게시글의 상태 변경이나 삭제는 수행하지 않음
